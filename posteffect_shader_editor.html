Minecraft /posteffect シェーダー・ノードエディター

ノードをつないでポストエフェクトシェーダーを組み立て、Minecraft 26.3+ の /posteffect コマンドで使えるリソースパックとして書き出します。Blockbench変換ツールとは別の独立したツールです。すべてブラウザ内で完結し、サーバーには送信されません。

1パック情報

クリック、またはzipファイルをドラッグ＆ドロップして選択

以前このツールで生成したzipなら、全エフェクトをそのまま編集できる状態で復元します。他で作られたzipの場合は、パック名・名前空間・説明文だけ引き継ぎ、各エフェクトは元のファイルのまま（編集はできません）取り込みます。

2エフェクト一覧

3ノードエディター -

右クリックでノードを追加 / ソケット同士をドラッグして接続 / ノードを選択してDeleteで削除

🔒 既存パックから取り込んだエフェクトのため、ノードグラフを編集できません

Input: Scene Color / UV / Resolution / Number / Vector2 / Color / Uniform (調整可能な数値) / Time (経過時間・GameTime) / Depth (深度) Math: 四則演算・Mix・Clamp・Sin/Cos など Vector: Split / Combine / RGBA変換 Effect: Sample Offset・Grayscale・Hash Noise・Pixelate・Vignette Output: Fragment Output（最終カラーをここに接続。1つだけ必須）

4プレビュー

「経過時間 (GameTime)」ノードを使うとプレビューが自動でアニメーションします。ループ秒数は下のバーで調整できます（初期値はゲーム内と同じ1200秒＝20分）。
